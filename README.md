# 🎴 Research Flashcard

**Research Flashcard** is a lightweight, web-based flashcard application designed to display niche academic research topics in chemistry, mechanical engineering, physics, and robotics. Built as a simple HTML/JS single-page application, it works cross-platform without complex setup or dependencies.

---

## ⚡ Features

* **Auto-Shuffle**: Flashcard decks automatically shuffle upon loading to keep learning random and dynamic.
* **Flexible Navigation**: Seamlessly navigate through cards using touch gestures (**swipe left/right**) on mobile or **Previous / Next buttons**.
* **Zero Dependencies**: Lightweight and responsive design that scales from desktop browsers to smartphones.

---

## 📊 Demo Dataset

* Included in the repository is a demo dataset (`flashcards_2.csv`) containing 500+ granular research fields (e.g., Sonochemistry, Single-Atom Catalysis, Topology-Optimized Compliant Mechanisms).
* **Note**: The entire dataset and content were **generated using an LLM (Gemini)** for demonstration and deep-dive exploration.

---

## 📱 Quick Start & iOS Instructions

### 🍏 iOS (iPhone / iPad) Users
1. Download or install any **HTML Viewer** app from the App Store (or save `Flashcard.html` into the **Files** app).
2. Open `Flashcard.html` inside the HTML Viewer or Safari.
3. Import your `.csv` or `.md` flashcard files to start browsing.

### 💻 PC / Mac Users
* Double-click `Flashcard.html` to launch directly in Chrome, Edge, Safari, or VS Code Previewer.

## ⚠️ Known Issue / Developer Note

> **Image Search Feature**: 
> The original vision for this project included automatically fetching dynamic image/photo search results for each research card. However, due to browser CORS (Cross-Origin Resource Sharing) restrictions and blocked automated search API requests, this feature is currently disabled/blocked. 
> 
> As the creator of this project, **I am not familiar with HTML, JavaScript, or web development**, so contributions or PRs to safely resolve this photo fetching issue are highly welcome!
